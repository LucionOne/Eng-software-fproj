# Stakeholders — Calculator Project

## Primary Stakeholders

* **End Users**: students or instructors using the calculator to do arithmetic and quick computations.
* **Client**: course instructor / teaching assistant who will grade the assignment.
* **Team**: developers submitting the repo (authors of code and docs).

## Affected Parties

* **Other students** (peer reviewers) when used in demos or presentations.
* **System administrators** of lab machines where the app will be installed.

## Technical Stakeholders

* **Installer**: person who installs or runs the app on target machines (may be the user).
* **Maintainer**: teammate or future developer who will fix bugs and update the code.
* **CI/CD**: automated build/test pipeline that verifies PRs and runs unit tests.

## Security / Threat Model

* **Attacker (if applicable)**: someone who provides malformed input to break or exploit the calculator (e.g., extremely large numbers, injection via clipboard). Treat as low-severity for this assignment but documented.

## Regulators / Compliance

* **Course policy**: academic honesty and submission deadlines — the instructor/TAs enforce these rules.
